# Public release status

**Draft preview — no task is accepting candidate submissions yet.** Software
checks are available for exploration. No credits, GPU allocations, timers, or Astra runs
are issued by this repository. The task budgets and effort estimates remain proposals.

| Task | What must exist before invitations |
| --- | --- |
| Benchmark design | Validated AMD GPU quickstart, fixed measurement runner/event schemas, public fault/control fixtures, supplied enhanced agent, and a clean end-to-end pilot |
| Harness design | Validated GPU quickstart, licensed LLMD source/build access, isolated plain agent starter, implemented/calibrated private grader, and resource controls |
| Compute Quant | Frozen evidence/input contract and reproduction pilot; either licensed dated market evidence or an explicitly approved synthetic reasoning assignment |
| 20/20 puzzle | Published pinned Astra profile, trusted author/solver clocks, private upload channel, sandboxed verifier, packaging limits, and a full rehearsal |

The four tasks release independently. GPU bring-up is not a prerequisite for either
CPU-only task. Synthetic inputs must not be advertised as real market prices, and a
solver's infrastructure failure is not evidence of puzzle difficulty.

## What a released assignment will include

- An immutable starter commit and `takehome-start` tag, retained externally by the organizer.
- Clear editable/protected boundaries and runnable validation examples.
- An approved effort limit, calendar deadline, resources, retry policy, and accommodations.
- A rehearsed setup/submission flow, including private delivery of sensitive artifacts.
- A published task-specific release notice replacing the relevant draft warnings.

We will not silently change requirements, deadlines, or the evaluator mid-cohort.
The [candidate submission guide](../CONTRIBUTING.md) describes the planned fork/PR flow.
